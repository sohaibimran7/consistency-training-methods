# Archived source

`legacy/` contains the complete pre-refactor source files removed from their
live package locations. It is retained for direct comparison and recovery.
None of these modules is imported, packaged, linted, or collected as tests.

The other tracked subdirectories contain smaller components removed during the
same cleanup, including redundant command wrappers and an unused trait
implementation. New code must not import from `_archive/`.

Generated bytecode, operating-system metadata, and duplicate recovery copies
are ignored. Git history and the tracked `legacy/` tree retain the corresponding
source.
